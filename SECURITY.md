# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security reports.

Email <info@edgebites.com> with:

- affected version (`VERSION` file / `fw-black --version`)
- OpenWrt version and device
- steps to reproduce / logs (`logread -e fwblack`)

We will acknowledge receipt and coordinate a fix and disclosure.
Thank you for helping keep routers safe.
